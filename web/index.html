03 — Models

How well does it actually do?

Model R² MAE (kg/ha) MAPE (%)

The naive baseline repeats last year's yield and still beats both machine learning models on MAPE and MAE. That is the honest headline: for annual national yields, a crop's own last value is hard to improve on. The pooled R² looks high mainly because the models know which crop they are looking at.
